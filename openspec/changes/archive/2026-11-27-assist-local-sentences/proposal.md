# Proposal

## Why

`assist-logging` lets an LLM agent record entries, but Home Assistant's built-in agent, which understands fixed sentences without a cloud service, still cannot. With the built-in agent, Baby Calendar works by voice in a house without OpenAI or Anthropic. With an LLM agent and "Prefer handling commands locally", which this instance has on, the common sentences are handled instantly and for free, and only the rest goes to the LLM.

## What Changes

- The integration registers its own intents with Home Assistant: record each tracker's entry, start and stop the breastfeeding and sleep timers, record a dose, and undo the last entry recorded by voice.
- **Managed sentence files:** the integration writes Portuguese and English sentences for those intents to `custom_sentences/pt/baby_calendar.yaml` and `custom_sentences/en/baby_calendar.yaml` in the configuration folder, the built-in agent's documented place for custom sentences. It then reloads the agent.
  - The files hold the babies' and medications' names as lists, so they are rewritten when a baby is added, renamed or removed, or when its medications change.
  - The integration only touches files it wrote, which carry a "generated by Baby Calendar" header. A file of that name without the header is left alone, with a warning in the log.
  - The files are deleted when the last baby is removed.
- **Sentences per language.** Examples in Portuguese:
  - "mudei uma fralda molhada", "fralda suja há 10 minutos";
  - "bebeu um biberão de 90 ml de leite artificial";
  - "começa a mama esquerda", "acabou a mama";
  - "o Duarte adormeceu", "acordou";
  - "comeu sólidos";
  - "tirei 80 ml de leite";
  - "pesa 4200 gramas", "mede 52 centímetros", "tem 37,2 graus";
  - "dei a vitamina D";
  - "desfaz o último registo".

  With one baby the name is optional. "há N minutos" sets the time. Decimals are accepted with a comma or a point.
- **Spoken reply:** each intent answers in the sentence's language with what was recorded, for example "Registei biberão 90 ml leite artificial às 21:20", or why nothing was recorded (tracker not enabled, unknown baby, timer already running).
- **Undo:** undo deletes the most recent entry recorded by voice in the last 10 minutes. The built-in agent keeps no conversation, so the integration remembers it.
- README: the Voice assistant section covers the built-in agent, the managed files and the sentence list.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `voice-assistant` (added by `assist-logging`): adds requirements for intents, the managed sentence files, the replies and voice undo. Only ADDED deltas; this change is archived after `assist-logging`.

## Impact

- New `custom_components/baby_calendar/intents.py` (intent handlers) and `sentences.py` (building and writing the files), with the sentence templates in `custom_components/baby_calendar/sentences/pt.yaml` and `en.yaml`.
- `__init__.py`: write the files on setup, unload and removal of an entry, debounced; register the intents once.
- The recording, baby resolution and result text are shared with `llm.py` from `assist-logging`, moved to a common `voice.py`.
- `manifest.json`: `conversation` in `after_dependencies`.
- Dev dependencies: `hassil` and `home-assistant-intents`, so that tests can run sentences through the built-in agent.
- New `tests/test_intents.py` and `tests/test_sentences.py`.
- `README.md`.
- Writes to the configuration folder: `custom_sentences/pt/baby_calendar.yaml` and `custom_sentences/en/baby_calendar.yaml` only.
